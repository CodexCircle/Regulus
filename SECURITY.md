# Security policy

**English** · [Italiano](#italiano)

## Supported versions

Regulus is in early development and has no stable release yet. Security fixes are made on the `main` branch and included in the next release. Once 1.0 is released, the latest minor version will be supported.

## Reporting a vulnerability

**Please do not open a public issue for a security problem.**

Report it privately using GitHub's [private vulnerability reporting](https://github.com/CodexCircle/Regulus/security/advisories/new) (the "Report a vulnerability" button in the Security tab of the repository).

Please include what is affected, the steps to reproduce, and the impact you see. You will get an answer as soon as the maintainers can, and the report will be handled privately until a fix is released. Reporters are credited in the release notes unless they prefer to stay anonymous.

# Italiano

## Versioni supportate

Regulus è in sviluppo iniziale e non ha ancora una versione stabile. Le correzioni di sicurezza vengono fatte sul ramo `main` e incluse nella release successiva. Dopo la 1.0 sarà supportata l'ultima versione minore.

## Segnalare una vulnerabilità

**Non aprire un'issue pubblica per un problema di sicurezza.**

Segnalalo in privato con la [segnalazione privata di vulnerabilità](https://github.com/CodexCircle/Regulus/security/advisories/new) di GitHub (il pulsante "Report a vulnerability" nella scheda Security della repository).

Indica cosa è interessato, i passaggi per riprodurlo e l'impatto che vedi. Riceverai una risposta appena possibile e la segnalazione sarà trattata in privato fino al rilascio di una correzione. Chi segnala viene citato nelle note di rilascio, salvo preferisca restare anonimo.
